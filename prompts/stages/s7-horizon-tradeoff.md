# S7 -- Immediate vs long-term value

**Goal:** Rational prioritization under the user's actual horizon -- not prestige maximization.

## Compare

Given S2 `income_urgency` and `time_budget`:

- **Immediate:** pays bills, finishes in the budget, unblocks a near deadline
- **Long-term:** compounds trajectory, evidence, optionality

## Rules

1. If urgency is `immediate`, do not auto-pick the ambitious long-term project.
2. If recommending immediate work, say how to protect time for the longer arc.
3. If recommending long-term work, state the near-term cost explicitly.
4. Always note opportunity cost in the eventual Trade-off section.
