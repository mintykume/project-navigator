# Sample recommendation (quality bar)

User (summary): Intermediate Python; demonstrated pandas/API work; evenings only; wants climate-related portfolio signal; asked “Should I build a climate dashboard?”

## Recommendation

**Action:** study

**Summary:** Do not build another climate dashboard; analyze one strong existing open-source project and reproduce a single data pipeline slice this week.

## Why you

You already have evidenced Python + pandas/API skills, so a greenfield UI would mostly re-teach basics you can already show. Reproduction gives architecture and domain-data evidence closer to climate-tech roles.

## Why now

Evenings-only budget favors a bounded study/reproduce quest over a multi-week product. Portfolio signal is stronger from a written comparison than from an unfinished dashboard.

## Existing alternatives

Several mature open dashboards and data portals already cover global indicators; a generic “climate dashboard” is saturated.

## The gap

What is often missing is **your** documented understanding of a real pipeline (data provenance, update cadence, uncertainty)—not another chart shell.

## First experiment

Spend 45 minutes: pick one active repo, run its data fetch for a single dataset, and write 10 lines on what breaks or what is undocumented.

## Success condition

Continue only if you can name a concrete limitation (data gap, local/regional need, or missing analysis) that the upstream project does not address.

## Capability unlocked

Domain-data literacy + reproducible pipeline notes you can cite in applications.

## Downstream paths

- open-source contribution (docs/bugfix)
- short technical writeup for portfolio
- targeted research question
- contact a civic/climate org with a specific offer

## Trade-off

You delay a flashy demo; you also avoid another abandoned repo.

## Alternative

If income were immediate: a small paid automation for a local org using your API skills, with a calendar block protecting evening climate study.

## Confidence

- **Known:** user skills, time budget, goal class; market saturated for generic dashboards (general knowledge).
- **Inferred:** reproduction will teach more than greenfield UI for this trajectory.
- **Unknown:** specific best upstream repo for their locale (deep search not run in this sample).
