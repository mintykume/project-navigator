# Query pack: existing work

Intents to cover when deep-checking prior art:

| intent | Look for |
|--------|----------|
| `github_repos` | Repos, READMEs, stars/activity as weak signal only |
| `apps_products` | Shipped apps, SaaS, open alternatives |
| `papers` | Preprints / papers stating the problem |
| `datasets` | Public datasets that would make a project derivative |
| `apis_standards` | Existing APIs, RFCs, standards that remove the need to invent |

Classify each meaningful hit using `prompts/core-policy.md` existing-work table before recommending a greenfield build.
