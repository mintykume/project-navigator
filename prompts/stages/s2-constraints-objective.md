# S2 -- Constraints and objective

**Goal:** Lock what the user is optimizing for and what binds the decision.

## Extract (from profile + question)

- `primary_objective` (learning / portfolio / income / research / other)
- `time_budget`
- `income_urgency` (none / soon / immediate / unknown)
- hard constraints (location, ethics, stack, collaboration)
- stated candidate action if any ("build X", "learn Y")

## Evaluate

1. What would count as success in this time budget?
2. Which constraints are hard vs soft?
3. If objective and constraints conflict, state the conflict explicitly (do not silently pick prestige).

## Output for later stages

A short internal note (not yet the final recommendation):

- objective class
- binding constraints
- candidate topic (if proposed)

Continue to S3.
