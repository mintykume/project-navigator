# S5 -- Gaps

**Goal:** Identify what is actually missing -- not what sounds buildable.

## Inputs

- S2 candidate topic + constraints
- S4 facts if present; otherwise honest unchecked status

## Ask

1. What unmet need remains after existing alternatives?
2. Is the gap technical, distribution, domain knowledge, data, trust, or local context?
3. For beginners: is the "gap" actually a **learning** gap (study/reproduce is enough)?
4. If no meaningful gap: prefer study/contribute/dont over greenfield build.

## Output

One sentence gap statement (or "no meaningful product gap; learning/contribution path preferred").

Continue to S6.
